# PHP + MySQL Lab

[![Open in GitHub Codespaces](https://github.com/codespaces/badge.svg)](https://codespaces.new/OWNER/REPO)

## Start (students)

1. Click the **Open in GitHub Codespaces** button above, then **Create codespace**.
2. Wait 2-3 minutes the first time. Your website opens in a new tab automatically.
   (If not: click the **Ports** tab at the bottom, then the globe icon next to port 80.)
3. Edit files in the `public/` folder, save, and refresh the website tab.

## Useful things

- **Your website:** Ports tab → port 80
- **phpMyAdmin (database in the browser):** Ports tab → the phpmyadmin port
- **Database login:** user `student`, password `student`, database `labdb`
- **Starting data:** `database/init.sql`

## Save your work

Download your work: right-click the file list on the left → **Download...**.
Codespaces stop by themselves when idle. Delete old ones at github.com/codespaces
to save your free hours.
